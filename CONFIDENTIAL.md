# Confidential

This package contains **unreleased** material from the Kaijukaki collection:

- the **8888 pieces of art** at 128 px (`src/18a-sheets.js` and `desktop/app/art/`)
- the **complete metadata** — 20 trait layers, 35 races, 548 outfits, and the
  names of the 1/1 pieces

The collection **has not been minted yet**. None of this is public.

**What you can do:** run the game, read the code, build on top of it.

**What you cannot do:** publish or redistribute the art, publish the trait
list or the name list, upload this package (or any part of it) to a public
repository, an open bucket, an AI service that trains on what it receives,
or any place accessible to third parties. This includes the generated
build — `dist/kaijukaki.html` has the entire collection embedded in it.

If you need to host something for testing, host it on an origin with
authentication, and read `docs/03-ANTI-SPOILER-SECURITY.md` first — serving
the whole `dist/` folder statically is security hole number one.

If in doubt about what can leave this environment, ask the owner first.

— Oekaki Connect
